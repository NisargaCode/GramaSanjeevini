# GramaSanjeevini

GramaSanjeevini is an Android healthcare application developed using Kotlin, Jetpack Compose, and Firebase Firestore. The application helps villagers search medicine availability in nearby medical shops and allows pharmacists to manage medicine inventory efficiently through a cloud-based system.

---

# Features

## Villager Features
- Role-Based Access
- Villager Login
- Villager Home Dashboard
- Medicine Search
- Emergency Drug Availability
- Real-Time Medicine Availability Check

## Pharmacist Features
- Pharmacist Login
- Pharmacist Dashboard
- Inventory Management
- Medicine Stock Update
- Medicine Availability Management

---

# Firebase Integration

Firebase Firestore is used for:
- Medicine Data Storage
- Real-Time Data Retrieval
- Inventory Management
- Cloud Database Operations

Firebase Authentication is used for:
- Villager Login
- Pharmacist Login
- Role-Based Access Management

---

# Project Objective

The main objective of GramaSanjeevini is to provide an easy and accessible healthcare support platform for villagers by enabling medicine availability checking and helping pharmacists manage medicine inventory efficiently using cloud-based technologies.
